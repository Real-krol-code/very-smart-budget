# Тест-кейсы


## Бюджет и категории

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| BUD-01 | Создать бюджет с корректными категориями, проценты в сумме дают 100% | 201, бюджет успешно сохранён |
| BUD-02 | Сумма процентов равна 99% или 101% | 400, запрос отклонён согласно бизнес-правилам |
| BUD-03 | Передать отрицательный процент или лимит | 400, валидационная ошибка |
| BUD-04 | Три равные категории при доходе 100 000,00 | Сумма ровно 100 000,00: 33 333,33 + 33 333,33 + 33 333,34; остаток распределён |
| BUD-05 | Передать пустое название категории или дублирующую категорию | 400 при пустом названии, 409 если дубликаты не предусмотрены |
| BUD-06 | Изменить существующее распределение | 200, новые значения сохранены, старые не затронуты |
| BUD-07 | Изменение лимита в середине периода | 200, факт не меняется, процент и остаток пересчитаны, пороги переоценены, запись аудита создана |
| BUD-08 | Удаление категории с транзакциями | Категория архивируется, транзакции переходят в «Без категории», история и общий факт сохранены |
| BUD-09 | Копирование бюджета на следующий месяц | 201, категории и проценты перенесены, лимиты пересчитаны от нового дохода, транзакции не копируются |
| BUD-10 | Изменить бюджет, передав несуществующий ID категории | 404, изменения не сохраняются |
| BUD-11 | Изменить лимит после достижения порога 80% или 100% | 200, факт и остаток пересчитаны, состояние уведомлений соответствует согласованным правилам |

## Лимиты, алерты и пороги

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| ALR-01 | Факт 79,99% лимита | Алерт не создан |
| ALR-02 | Факт ровно 80,00% | Создан один алерт 80%, запись в центре уведомлений |
| ALR-03 | Факт 80,01% и последующие траты | Алерт 80% один раз, повторов нет |
| ALR-04 | Факт ровно 100,00% | Алерт 100%, алерт 80% уже существует, порядок 80 → 100 |
| ALR-05 | Импорт переводит категорию с 40% сразу на 105% | Созданы оба алерта, по одному, в порядке 80 → 100 |
| ALR-06 | Дальнейший рост выше 100% | Новых алертов нет |
| ALR-07 | Перекатегоризация вводит траты в категорию и даёт 80% | Алерт создан один раз |
| ALR-08 | Перекатегоризация выводит траты из категории | Новых алертов нет; исторический алерт сохраняется как событие периода |
| ALR-09 | Лимит понижен ниже текущего факта | Алерт 100% создан, если по этому порогу ещё не было уведомления; повторно не создаётся |
| ALR-10 | Новый период | Счётчики порогов сброшены, алерты могут создаваться заново |
| ALR-11 | Нулевой, удалённый или отсутствующий лимит | Алерты не создаются, деления на ноль нет |
| ALR-12 | Содержимое алерта | Категория, факт, лимит, процент, период, ссылка; текст на русском, сумма в RUB |
| ALR-13 | Ошибка push-провайдера | Алерт и запись в центре созданы, статус доставки FAILED, выполнен ретрай |
| ALR-14 | Категория без лимита | Алерт не создаётся |
| ALR-15 | Возврат снижает факт, затем повторный рост | Повторный алерт не создаётся в том же периоде |
| ALR-16 | Изменение лимита после отправки 80% | Новый алерт 80% не создаётся; 100% срабатывает по достижении |
