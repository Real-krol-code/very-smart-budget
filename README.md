## О проекте

> **Finance App** — это учебный продукт, создаваемый командой из 4 человек в рамках Проектного практикума (осень 2026). Мы эмулируем реальный рабочий процесс: от аналитики и проектирования до презентации заказчику.

## Git Workflow

В команде настроен строгий процесс ветвления:

- `main` — продакшн (обновляется раз в сутки/по готовности).
- `develop` — интеграция фич.
- `qa` — ветка для тестирования.
- `dev_Vlad` / `dev_Senya` — личные ветки разработчиков.
